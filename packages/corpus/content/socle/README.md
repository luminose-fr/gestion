# socle/

Identité, positionnement, audience, offres (**avec statut**), tarifs, cadre déontologique et
juridique.

Chargé par **tous** les cas d'usage qui produisent quelque chose au nom de Luminose.

Le cadre déontologique gagne tous les arbitrages : une promesse de guérison dans une annonce
Google est un risque réel, pas une faute de goût.

`ce-qui-fonctionne.md` a un statut à part : c'est le contrepoids du journal des décisions —
ce qui tourne ne produit aucune fiche datée, donc il faut l'écrire à la main. La fiche dit
elle-même pourquoi elle existe et ce qu'on n'a pas le droit d'en faire.
