# outils/

Inventaire du parc et des process.

Chargé par le profil `complet` comme les autres blocs stables, mais il ne sert vraiment qu'un
cas d'usage : « je veux me questionner sur mes outils, automatiser des trucs, améliorer mes
process ».

`parc.md` **fait foi sur le prestataire d'encaissement**. Deux prestataires coexistent —
Stancer pour l'individuel, Stripe pour le groupe — et deux fiches d'offre les citent : un
changement se répercute dans les trois.
